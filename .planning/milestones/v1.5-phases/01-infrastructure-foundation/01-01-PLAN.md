| Boundary | Description |
|----------|-------------|
| host network -> published container ports | Memgraph OSS Bolt (7687) and Qdrant (6333/6334) have NO authentication in this configuration. Any process able to reach these ports has full read/write on the topology and knowledge planes. |
| Memgraph Lab browser session -> Memgraph Bolt | Lab executes arbitrary operator-supplied Cypher with no authorization layer. |
| developer filesystem -> git history | `.env` will hold a live `ANTHROPIC_API_KEY`. |
| PyPI / Docker Hub -> local build | Third-party package and image content is executed on the developer machine. |
