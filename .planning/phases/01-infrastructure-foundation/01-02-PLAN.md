<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host -> ClickHouse HTTP 8123 | SigNoz's bundled ClickHouse runs as the `default` user with an empty password. Anyone reaching 8123 has unrestricted DDL and DML across all signoz_* databases. |
| host / network -> OTLP receiver 4317 / 4318 | The collector accepts unauthenticated telemetry. Any writer can inject arbitrary log bodies and forge `service.name` resource attributes. |
| host -> SigNoz frontend 3301 | Before the first-run admin account is created, the setup flow is reachable by anyone who can load the page. |
| foundryctl download -> local execution | A third-party binary is fetched and executed to generate infrastructure manifests. |
| generated manifest -> committed manifest | The generated output is committed and then run on every machine. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-08 | Spoofing | ClickHouse `default` user, empty password, port 8123 | mitigate | Published as `127.0.0.1:8123:8123` only, and native TCP 9000 is not published at all. Acceptance criterion asserts `docker compose ps --format '{{.Ports}}' \| grep -c '0\.0\.0\.0'` returns 0. |
| T-01-09 | Spoofing | Unauthenticated OTLP ingress on 4317/4318 | accept | Rationale: the collector must accept telemetry from 14 unauthenticated demo containers; adding OTLP auth would require re-instrumenting the OTel demo, which is explicitly out of scope. Bound to loopback plus the internal `incimin` network. The injected data is synthetic demo telemetry with no trust consequence. Revisit before any shared-network deployment (v2 SEC-02 audit-log work). |
| T-01-10 | Tampering | Telemetry injection forging `service.name` | accept | Rationale: Task 3 deliberately exercises this capability to prove the ingress works. Downstream Phase 3 tools read telemetry as evidence for a human-reviewed recommendation and never execute on it (AGENT-05 forbids remediation execution), so a forged record degrades RCA quality but cannot cause an action. |
| T-01-11 | Tampering | foundryctl binary provenance | mitigate | Pin to the exact release v0.2.17 and record the install command plus `foundryctl version` output in the SUMMARY. Discover the CLI surface from `--help` rather than assuming flags.
